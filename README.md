# 🧹 ProductDoctor — Доктор товарных файлов

Плагин для [FunPay Cardinal](https://github.com/sidor0912/FunPayCardinal) **v0.1.17+**

Проверяет и лечит товарные файлы автовыдачи (`storage/products/*.txt`).
Главная угроза, которую он ловит — **дубликаты товаров**: один и тот же товар
может быть выдан двум покупателям одновременно → возврат + негативный отзыв.

## Возможности

- 🔍 **Полная диагностика** каждого товарного файла:
  - 🚨 дубликаты (сколько лишних копий и какие — в маскированном виде);
  - ⚠️ пустые строки, пробелы по краям (ломают логины/пароли),
    подозрительно короткие строки.
- 🧹 **Очистка файла** одной кнопкой: убирает дубликаты (оставляет первое
  вхождение), пустые строки и лишние пробелы. **Перед очисткой создаётся бэкап**
  (`имяфайла.bak`) — ничего не потеряется.
- 🧹 **Массовая очистка** дубликатов во всех файлах сразу (с подтверждением).
- 🔁 **Авто-проверка** (по умолчанию раз в 6 часов): если в файлах ПОЯВИЛИСЬ новые
  дубликаты — придёт 🚨 уведомление. Без спама: повторно предупреждает только
  когда дубликатов стало ещё больше.
- 👻 Находит «сирот» — файлы в `storage/products`, не привязанные ни к одному лоту.
- 🔒 **Приватность**: товары (логины/ключи) никогда не показываются в Telegram
  целиком — только маскированные превью (`log***`).
- Все операции с файлами идут под штатным локом Кардинала
  (`get_products_file_lock`) — безопасно даже во время активной автовыдачи.

## Установка

```bash
cd /home/fpc/FunPayCardinal
wget https://raw.githubusercontent.com/yungspiderq/FPC-ProductDoctor/main/product_doctor.py -O plugins/product_doctor.py
sudo systemctl restart FunPayCardinal@fpc
```

или отправьте файл боту в Telegram → `🔌 Плагины` → `➕ Добавить плагин`.

## Использование

Команда **`/products`** (или `⚙️ Настройки` на странице плагина):

| Кнопка | Действие |
|---|---|
| 📦 Файлы товаров | Список файлов: 🚨 дубликаты / ⚠️ мелкие проблемы / ✅ чисто / 👻 сирота |
| 🧹 Очистить дубликаты везде | Массовая очистка всех проблемных файлов (с подтверждением) |
| 🔁 Авто-проверка: ВКЛ/ВЫКЛ | Фоновый мониторинг новых дубликатов |
| ⏱ Интервал: 6 ч. | Как часто проверять автоматически (в часах) |

Страница файла: количество товаров, список дубликатов (маскированно), мелкие
проблемы, наличие бэкапа и кнопка **🧹 Очистить файл**.

## Важно знать

- Дубликатом считается точное совпадение строки (после обрезки пробелов).
  При очистке остаётся **первое** вхождение, порядок товаров сохраняется.
- Бэкап `.bak` перезаписывается при каждой очистке файла.
- Подозрительно короткие строки (< 3 символов) только помечаются в отчёте —
  автоматически не удаляются (вдруг это валидный товар).
- Плагин не делает запросов к FunPay — работает только с файлами на диске.
- Настройки: `storage/plugins/product_doctor/settings.json`.

## Состав репозитория

- `product_doctor.py` — плагин (класть в `plugins/`).
- `tests_plugin_product_doctor.py` — тесты (44 проверки на моках: анализ, очистка,
  бэкапы, маскирование секретов, авто-проверка без спама, весь Telegram-UI).
  Запуск из корня FunPayCardinal:
  ```bash
  cp tests_plugin_product_doctor.py /path/to/FunPayCardinal/
  cd /path/to/FunPayCardinal && pip install -r requirements.txt && python3 tests_plugin_product_doctor.py
  ```
